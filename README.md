Refresh-aware earners/players forecaster for GTA VI PS5 trophy earn rates on Exophase: it inverts the launch-night refresh from the published totals, and on richer histories blends persistence, a damped log-time logit trend and an earners/players decomposition weighted by a time-split backtest.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
